# Portfolio | Peerzada Mohammad Sameem Makhdoomi

A cybersecurity- and network engineering-focused portfolio inspired by the TryHackMe *Mr. Robot* CTF theme. Built with an interactive terminal, dynamic Three.js 3D data pipeline, and verified career telemetry.

🌐 **Live Demo:** [ft10101.github.io/portfolio](https://ft10101.github.io/portfolio/)

---

## Highlights

- **Aesthetic:** Dark cybersecurity theme with subtle CRT scanline overlays and responsive styling.
- **Interactive Shell:** In-browser terminal executing commands (`help`, `whoami`, `experience`, `research`, `skills`, `nmap`).
- **3D Network Spine:** Procedural Three.js particle canvas reacting to user scroll.
- **Verified Background:** Enterprise network operations, peer-reviewed AI security research, and DEF CON leadership.

---

## Tech Stack

- **Frontend:** HTML5, [Tailwind CSS](https://tailwindcss.com/)
- **3D Visuals:** [Three.js](https://threejs.org/)
- **Typography:** Fira Code & JetBrains Mono
- **Deployment:** GitHub Pages (Static, zero dependencies)

---

## Deployment to GitHub Pages

1. Commit `index.html` and `README.md` to your repository's `main` branch.
2. In your repo, go to **Settings** → **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. The site will publish live at `https://<your-username>.github.io/<repo-name>/`.
